# AI Chatbot

A responsive browser-based chatbot interface built with HTML, CSS, and JavaScript.

## Features
- Chat interface with message timestamps
- Typing indicator and responsive layout
- Gemini API request code with error handling

## Run locally
Open the project folder in VS Code and launch `index.html` with Live Server.

## Note
The API key is not included. Secure Gemini responses require a backend; do not add the key to browser code.
